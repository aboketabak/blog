Un petit script Python pour agréger plusieurs flux RSS et envoyer un résumé quotidien.

## Utilisation

```bash
python rss_agregateur.py --config sources.yml
```

## Prérequis

- Python 3.10+
- feedparser
- smtplib (inclus)
