Publier son blog sur GitHub Pages

// 03 JUIN 2025  |  3 MIN DE LECTURE

Héberger un site statique gratuitement n'a jamais été aussi simple. GitHub Pages permet de publier n'importe quel dossier HTML/CSS directement depuis un dépôt Git, sans serveur, sans configuration complexe.

Étape 1 — Créer le dépôt

Créez un nouveau dépôt public sur GitHub. Nommez-le monusername.github.io pour avoir une URL propre, ou n'importe quel autre nom si vous préférez une URL en sous-dossier.

Étape 2 — Pousser vos fichiers

Ajoutez vos fichiers HTML, CSS et images dans le dépôt. Un simple git push suffit. GitHub s'occupe du reste automatiquement.

"Un blog statique, c'est zéro base de données, zéro faille, zéro facture d'hébergement."

Étape 3 — Activer GitHub Pages

Dans les Settings du dépôt, section Pages, sélectionnez la branche main et le dossier racine. Votre site est en ligne en moins d'une minute.
